# Table Library

## 函数

| 函数 | 说明 |
|------|------|
| `table.concat(t [, sep [, i [, j]]])` | 拼接数组元素 |
| `table.insert(t, [pos,] value)` | 插入元素 |
| `table.remove(t [, pos])` | 移除元素 |
| `table.sort(t [, comp])` | 排序 |
| `table.maxn(t)` | 最大正索引 |
| `table.getn(t)` | 表长度 (5.1 兼容) |
| `table.foreach(t, f)` | 遍历 (5.1 兼容) |
| `table.foreachi(t, f)` | 数组遍历 (5.1 兼容) |
