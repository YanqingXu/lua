# Known Incompatibilities — 已知不兼容

## 关键不兼容

| 项目 | 技术差异 |
|------|----------|
| **官方 binary chunk** | 使用项目本地格式，不与官方 chunk 互通 |
| **testC helper (ltests.c)** | 未提供官方测试专用的内部 `T` 模块 |
| **IncrementalGC** | 策略入口委托给标记清除实现，不具备官方增量调度语义 |
| **错误消息文本** | 错误类别对齐，但具体措辞可能不同 |
| **#t 未定义行为** | 有洞表的边界选择可能与官方实现不同 |
| **长字符串处理** | 所有字符串统一驻留，内存与比较策略不同 |

## 标准库差异

| 函数 | 差异说明 |
|------|---------|
| `table.setn` | Lua 5.1 已废弃，未实现 |
| `collectgarbage("step")` | 分阶段推进，但非增量式 |
| `os.execute` | Windows 引号包装方式不同 |
| `package.loadlib` | 搜索路径实现细节不同 |
