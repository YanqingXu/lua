# Known Limitations — GC 已知限制

## 当前未支持

| 项目 | 说明 |
|------|------|
| **Incremental GC** | 策略接口已定义，当前为教学占位 |
| **Generational GC** | 无分代回收 |
| **Finalizer 完整语义** | 两阶段 finalizer 已实现，精细边界待验证 |

## 当前风险

| 风险 | 说明 |
|------|------|
| 循环引用回收 | 已验证通过标记-清除正确处理 |
| 长时间运行内存增长 | 待长期压力测试验证 |
| 字符串池释放 | 字符串驻留后不会被释放 (生命周期 = 整个程序) |
| GC 暂停时间 | 标记-清除是 stop-the-world，大堆时可能卡顿 |

## 设计说明

当前 GC 优先保证正确性，而非性能。GCStrategy 接口的存在允许未来替换为增量或并发 GC。
