# 排版规则

本项目现有 [.clang-format](../../.clang-format) 是 C++ 布局的唯一配置来源：LLVM 基础、4 空格、120 列、Attach 花括号。适用范围与增量采用见 [规则入口](README.md)，不迁入 Hunter 的 100 列或另起行花括号。

### R-FORMATTING-01 遵循仓库配置

- **等级：MUST。**
- **范围：** 新增或实际修改的自有 C++；工具检查所选文件整体。
- **要求：** 使用 4 空格而非 Tab，按 120 列目标折行，左花括号附着于声明或控制语句；指针/引用按配置左对齐。保留 include 顺序和分组，不因其他项目偏好重写根配置。
- **例外：** 工具无法安全拆分的字面量、完整 URL 或外部标识可保持原样；必要的局部 `clang-format off/on` 需成对且说明具体原因。第三方与生成产物按入口排除。
- **验证：** 按根配置执行格式检查并审阅 diff；工具输出不能证明类型、求值或宏语义未改变。

### R-FORMATTING-02 控制体显式使用花括号

- **等级：MUST。**
- **范围：** 新增或修改的 C++ `if`、`else`、`for`、`while`、`do` 与 `switch` 结构。
- **要求：** 执行体显式使用花括号，单条语句也不省略；空循环写出块及必要意图，不用孤立分号隐藏空体。分支不压成一行。
- **例外：** `else if` 可直接连接条件；`case` 标签不要求机械增加独立块，按声明作用域需要处理。宏/外部契约应保持语法和语义并人工说明，不能扩大为普通函数的豁免。
- **验证：** 人工逐项检查触及的控制结构；当前格式配置不会补齐所有花括号，tidy 的范围和短语句设置也不是本规则的全量门禁。

```cpp
if (!ready) {
    return;
} else if (hasPendingWork) {
    processPendingWork();
} else {
    finish();
}
```

示例只演示布局，不定义运行时接口。

### R-FORMATTING-03 用空行表达完整阶段

- **等级：SHOULD。**
- **范围：** 函数、声明组和局部流程。
- **要求：** 相邻函数或不同职责阶段用一行空行分隔；注释与其解释的声明保持相邻。完整 `if/else`、`do/while` 保持连续，初始化与紧随其后的条件可作为一组。
- **例外：** 紧凑声明组、表格数据和强顺序局部步骤可连续排列；不在每个控制结构前后机械插空行，不在块首尾制造空行。
- **验证：** 人工顺着阅读路径检查分组；以根格式配置为准，不另建与 formatter 竞争的逐行排版算法。

### R-FORMATTING-04 折行不改变表达式

- **等级：MUST。**
- **范围：** 长条件、签名、调用、预处理指令和字面量。
- **要求：** 先按语义和配置折行；不为行宽缩短明确名称、改变签名、提前求值或制造无职责 wrapper。保留短路、左右求值顺序、临时对象生命周期、宏续行和字符串内容。
- **例外：** 确有独立含义的中间结果或 helper 可提取，但属于 [重构](refactoring_rules.md)，需相应语义审查。
- **验证：** 核对 token、字面量与预处理边界；实际改变结构时验证受影响路径，不能仅报告格式检查通过。

### R-FORMATTING-05 控制格式修改范围

- **等级：MUST。**
- **范围：** 人工或工具格式化。
- **要求：** 新文本使用 UTF-8，服从 [.gitattributes](../../.gitattributes)，避免无关 BOM、编码或整仓换行变动。Changed 选中的是文件，格式检查和修复均处理其整体；必要的同文件格式整理与逻辑变化保持可区分。
- **例外：** 明确范围的格式专项可批量整理；上游固定材料和生成产物仍不手改。既有编码问题确需修复时单独说明。
- **验证：** 审阅文件清单与差异，确认没有误及其他目录、许可证或生成文件；不以检查失败为由直接执行全仓格式化。

### R-FORMATTING-06 其他语言遵循各自语法

- **等级：MUST。**
- **范围：** 自有 Lua、Python、PowerShell、CMake 等脚本与纯 C 文件。
- **要求：** 沿用所属语言和文件的有效格式；Lua 以 `end` 对齐结构，Python 保持缩进语义，PowerShell/CMake 保持引号与展开规则。通用可读性与范围约束同样适用，C++ 类型别名和花括号规则不跨语言套用。
- **例外：** 格式工具可能把自有 C 文件纳入选中范围；保持其 C 合法性和 ABI，不能因此引入 C++ 语法。固定上游脚本保持原样。
- **验证：** 按语言检查语法、内容与必要行为；没有对应自动格式工具时记录人工检查，不宣称 C++ formatter 已覆盖脚本。
