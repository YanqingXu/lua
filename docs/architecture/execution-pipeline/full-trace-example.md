# Full Trace Example — 全链路追踪

## 1. 这个模块解决什么问题？

用一个最小 Lua 脚本，从头到尾追踪它在解释器中的完整执行流程。**这是整个文档体系中最重要的一份文档**。

## 2. 示例脚本

```lua
local x = 1

local function add(a, b)
    return a + b + x
end

print(add(2, 3))
```

## 3. Stage 1: Source Code（源码）

```
第 1 行: local x = 1
第 2 行: (空行)
第 3 行: local function add(a, b)
第 4 行:     return a + b + x
第 5 行: end
第 6 行: (空行)
第 7 行: print(add(2, 3))
```

## 6. Stage 4: Generated Bytecode（编译输出）

### 主 Chunk 的 Proto

```
main Proto {
  maxStackSize: 4
  params: 0
  isVararg: true
  
  constants: [
    K(0): 1,
    K(1): "print",
    K(2): 2,
    K(3): 3
  ]
  
  sub protos: [
    add Proto  ← 子函数原型
  ]
  
  upvalues: []  ← 主 Chunk 不捕获外部变量
  
  code: [
    0: LOADK     R(0) K(0)     ; R(0) = 1
    1: CLOSURE   R(1) sub[0]   ; R(1) = closure(add), upvalue: R(0)
    2: SETLOCAL  R(0) R(1)     ; local x = 1, local add = closure
    
    3: GETGLOBAL R(0) K(1)     ; R(0) = print
    4: GETLOCAL  R(1) ?        ; R(1) = add (闭包)
    5: LOADK     R(2) K(2)     ; R(2) = 2
    6: LOADK     R(3) K(3)     ; R(3) = 3
    
    7: CALL      R(1) 2 1      ; R(1)(R(2), R(3)) → R(1) = add(2, 3) = 6
                                ;   A=1: func在R(1)
                                ;   B=2: 2个参数(a=2, b=3)
                                ;   C=1: 期望1个返回值
    
    8: CALL      R(0) 1 1      ; R(0)(R(1)) → print(6)
                                ;   A=0: func在R(0)
                                ;   B=1: 1个参数
                                ;   C=1: 期望1个返回值
    
    9: RETURN    R(0) 1         ; 返回 0 个值
  ]
}
```

### add 子函数的 Proto

```
add Proto {
  maxStackSize: 3
  params: 2        ← a, b
  isVararg: false
  
  constants: []
  
  upvalues: [
    UpvalueDesc(0): 栈层级 0 的局部变量 → x
  ]
  
  code: [
    0: ADD       R(2) R(0) R(1) ; R(2) = a + b
    1: GETUPVAL  R(3) 0         ; R(3) = upvalue[0] = x
    2: ADD       R(2) R(2) R(3) ; R(2) = (a+b) + x
    3: RETURN    R(2) 2         ; 返回 R(2) (共1个值)
  ]
}
```

## 7. Stage 5: Runtime Objects（运行时对象）

```
主 Chunk 的 Function (Lua Closure)
  ├── Proto (main)
  ├── upvalues: []  (主 chunk 无 upvalue)
  └── env: _G 表

add 的 Function (Lua Closure)
  ├── Proto (add)
  ├── upvalues: [
  │     Upvalue 0 → 指向 x 的栈位置
  │       状态: Open (因为 x 还在栈上)
  │   ]
  └── env: _G 表

Upvalue (x):
  ├── v_ → 栈上 x 的位置
  ├── stackIndex: 0
  ├── 状态: Open
  └── (主 Chunk 返回后变为 Closed)
```

对象关系图：

```
main Function
  ├── Proto (字节码)
  └── (无 upvalue)

add Function
  ├── Proto (字节码: GETUPVAL 0)
  └── Upvalue[0] ──→ 栈[0] (x = Value(1))
```

## 8. Stage 6: VM Execution（虚拟机执行过程）

### 初始化

```
LuaState 创建:
  Stack: [0..N] (预分配)
  CallInfo[0]: {
    func:   (虚拟主函数)
    base:   0
    top:    0
    savedpc: null
  }

VM::executeProto(main Proto):
  proto = main Proto
  base = &stack[0]
  pc = 0
```

### 逐指令执行

```
pc=0: LOADK  R(0) K(0)
  R(0) = constants[0] = Value(1.0)
  --- 栈: [1.0, ...]

pc=1: CLOSURE  R(1) sub[0]
  创建 add Closure:
    proto = subProtos[0] = add Proto
    upvalues = [findOrCreateUpvalue(x in stack[0])]
  R(1) = Function(add_closure)
  --- 栈: [1.0, Function(add), ...]

pc=2: SETLOCAL  R(0) R(1)
  (SETLOCAL 是伪指令，实际操作已包含在前面的 LOADK/CLOSURE 中)
  --- x = R(0) = 1.0, add = R(1) = Function(add)

pc=3: GETGLOBAL  R(0) K(1)
  R(0) = _G["print"] = Function(print)
  --- 栈: [Function(print), Function(add), ...]

pc=4: GETLOCAL  R(1) add
  R(1) = Function(add)
  --- 栈: [Function(print), Function(add), ...]

pc=5: LOADK  R(2) K(2)
  R(2) = constants[2] = Value(2.0)
  --- 栈: [Function(print), Function(add), 2.0, ...]

pc=6: LOADK  R(3) K(3)
  R(3) = constants[3] = Value(3.0)
  --- 栈: [Function(print), Function(add), 2.0, 3.0]

pc=7: CALL  R(1) 2 1
  调用 add(R(2), R(3)) → add(2, 3)
  
  1. 创建新 CallInfo:
     ci[1].func = 1  (add 函数在栈索引 1)
     ci[1].base = 2  (参数从索引 2 开始: 2.0, 3.0)
     ci[1].top = ci[1].base + addProto.maxStackSize = 2 + 3 = 5
     ci[1].nresults = 1
  
  2. 切换到 add 的 Proto 执行:
     --- add 帧栈: [2.0(a), 3.0(b), nil, nil, nil]
     add pc=0: ADD R(2) R(0) R(1)
       R(2) = R(0) + R(1) = 2.0 + 3.0 = 5.0
     add pc=1: GETUPVAL R(3) 0
       R(3) = upvalue[0] = x = 1.0
     add pc=2: ADD R(2) R(2) R(3)
       R(2) = R(2) + R(3) = 5.0 + 1.0 = 6.0
     add pc=3: RETURN R(2) 2
       返回 1 个值: R(2) = 6.0
  
  3. 返回到 main 帧:
     --- main 帧栈: [Function(print), 6.0, ...]
     --- add 的返回值 6.0 放到了 add 函数原来的位置 (R(1))

pc=8: CALL  R(0) 1 1
  调用 print(R(1)) → print(6.0)
  
  1. 创建新 CallInfo:
     ci[1].func = 0  (print 函数在栈索引 0)
     ci[1].base = 1  (参数从索引 1 开始)
  
  2. 执行 print:
     → 输出 "6" 到 stdout
  
  3. 返回到 main 帧

pc=9: RETURN  R(0) 1
  main 函数返回（程序结束）
```

## 9. Stage 7: Final Output（最终输出）

```
stdout:
6
```

## 10. 关键观察点

1. **local x = 1** → LOADK 将 1 放入 R(0)，R(0) = x
2. **add 定义** → CLOSURE 创建闭包，捕获 R(0) (即 x) 作为 upvalue
3. **add(2, 3)** → CALL 创建新帧，参数 a=R(0)=2, b=R(1)=3
4. **a + b + x** → ADD + GETUPVAL + ADD，其中 x 通过 upvalue 访问
5. **return** → RETURN 将结果 6.0 放回调用者栈
6. **print(6)** → CALL print，输出到 stdout

## 11. 这个示例覆盖的模块

| 模块 | 覆盖内容 |
|------|---------|
| Lexer | 关键字识别、字面量解析、标点符号 |
| Parser | 局部变量声明、函数定义、函数调用、二元表达式 |
| CodeGen | LOADK、CLOSURE、GETGLOBAL、CALL、ADD、GETUPVAL、RETURN |
| VM | 数据移动、函数调用、栈帧管理、Upvalue 访问、返回值传递 |
| Function | Proto、Closure、Upvalue 创建和绑定 |
| Value | Number 类型、Function 类型 |
